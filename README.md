## Run Locally

**Yêu cầu cài đặt:**  Node.js


1. Tải thư viện:
   `npm install`
2. Cài dặt`GEMINI_API_KEY` vào [.env.local](.env.local)
3. Chạy demo:
   `npm run dev`
